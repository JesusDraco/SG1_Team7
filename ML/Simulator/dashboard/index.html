Why this dashboard matters

This dashboard shows how different energy management strategies affect a neighborhood’s dependence on the grid, self-consumption, costs, and battery usage. The goal is not only to visualize data, but to explain which strategy creates the most balanced and resilient local energy behavior.

What changed with Machine Learning?

The original simulator used a perfect mathematical solar curve. That was useful for testing, but it ignored clouds, humidity, temperature, and real-world weather variation.

Before

Ideal Solar Simulation

Solar generation followed a clean sine-wave curve. The system behaved as if every day had perfect sunlight.

Now

Weather-Based Prediction

Solar generation is predicted using real weather data and a linear regression model implemented from scratch.

Impact

More Realistic Digital Twin

Battery behavior, grid import, export, and self-consumption now react to realistic solar variability.
